PROOF RULE (hard): NEVER state a fact, status, or decision from assumption, memory, or inference — verify it first with a command that could fail (git ls-remote, gh pr view, grep the actual file) and base the action on that output. This governs branches/PRs/deploys especially: before claiming code is pushed, on the right branch, merged, or deployed, PROVE it (remote tip SHA, PR state + head ref, deployed image). If you cannot prove it, say so explicitly — do not assert. No assertions, only proof.
