INVESTIGATE-FIRST RULE (hard): before writing ANY code, fully map the feature area — not one sibling. Survey every peer action on the same surface (all writes/mutations, frontend + backend), how each is already gated/authorized, and which layer enforces it. Model the fix on a prior-art pattern you can point to and keep it consistent across the whole surface. If you can't name the pattern, or the right layer/scope is ambiguous, STOP and ask BEFORE coding. Never bolt a one-off onto a single affordance without checking its siblings and its backend.
